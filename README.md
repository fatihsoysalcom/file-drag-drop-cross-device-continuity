# File Drag Drop Cross Device Continuity

This example demonstrates local file drag and drop functionality in a web browser. Users can drag a file from their local file system into a designated drop zone. Upon dropping, the file's content is displayed (e.g., image preview, text content), and its Base64 representation is shown, illustrating how data can be converted into a universally transferable format to facilitate cross-device continuity.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in any modern web browser.
3. Drag and drop an image or text file from your computer into the designated drop zone.
